# Third-party files in this directory

`tmlr.sty`, `tmlr.bst`, `fancyhdr.sty`, `math_commands.tex` are the official LaTeX style files of *Transactions on Machine Learning Research*, copied unchanged from
<https://github.com/JmlrOrg/tmlr-style-file> (Apache License 2.0, `LICENSE-tmlr-style`). `math_commands.tex` is the optional notation file of
<https://github.com/goodfeli/dlbook_notation>. Everything else in `paper/` is part of this project.
